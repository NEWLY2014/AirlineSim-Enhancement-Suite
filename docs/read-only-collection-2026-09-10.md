# 当前游戏页面只读采集（2026-09-10）

首批将以下手动入口改为当前页面 content script 发起同源 GET，复用登录会话，解析返回 HTML，不打开目标标签页、不执行返回页面的脚本：

- 飞机航班列表：采集全部／已完成及飞行中航班财务数据，保存后刷新收益汇总。
- Dashboard：直接提取当前航司 schedule。
- 竞争对手：航司页面的 save all tab data，以及看板新增的 Refresh selected data，依次采集 overview、facts、schedule。

请求沿用全局页面队列。后台只发放许可，网络请求仍从发起操作的游戏页面执行。每次请求完成或取消后随机等待 30–70 毫秒，其他页面共享同一队列；网络、解析、轮询和浏览器调度可能使实际间隔更长。队列状态保存在 session storage，后台 worker 重启不会丢失队列。

校验 HTTP 状态、响应地址、登录航司、企业页签及所需字段，拒绝将登录页或不完整财务响应写成有效数据。当前页面导航、关闭或切换航司时停止后续采集。任务要求发起页面保持打开。每个数据集独立保存；批次失败时此前成功采集的数据保留，可重试。

Schedule 继续分段解析，并由后台合并历史记录，避免把大历史对象传回页面主线程。竞争对手历史保留现有追踪配置和已有同周 facts。定价、薪资、排班等交互操作不在本批范围；旧版本已挂起的自动跳页标记继续保留兼容处理。

验证：TypeScript 检查、188 项单元测试及 3 项 Chromium 测试通过。隔离 HTTPS 测试中，7 次目标读取均为携带测试会话的 GET，新增标签页为 0，跨页面请求实测完成后间隔 66 毫秒；队列单元测试覆盖 30／50／70 毫秒及 worker 重启。1 万航班、30 天历史的 schedule 浏览器测试通过，最大计时器间隔约 27 毫秒。浏览器验证使用本地页面夹具，未向真实游戏提交操作。
